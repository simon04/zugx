# Licence request: CP – Comboios de Portugal (GTFS)

Why: CP's GTFS is listed on NAP Portugal (record 176) as "No licence – No contract", and no
licence is stated anywhere else (see docs/europe-rail-data.md, Portugal). Under licence-first, we
build nothing on it before CP confirms reuse in writing.

- **To:** institucional@cp.pt (contact point and owner of NAP record 176)
- **Cc (optional):** IMT, the NAP publisher of the record — address still to find on
  https://www.imt-ip.pt (the record names an IMT staff member; use a general contact instead)
- **From:** Simon Legner — fill in the sender address when sending
- **Subject:** Pedido de autorização: reutilização do GTFS da CP (horários planeados) / Licence
  for reusing CP's GTFS

Send the Portuguese text; the English version below is the same message, for reference (or to
include under the Portuguese one).

## Português

Exmos. Senhores,

chamo-me Simon Legner e desenvolvo o **zugx** (https://zugx.legner.me), um site gratuito e sem
publicidade para consultar horários ferroviários — quadros de partidas, índice de comboios,
gráficos de circulação e pesquisa de ligações. O projeto é open source (AGPL-3.0,
https://github.com/simon04/zugx) e mostra atualmente a Áustria, a Eslovénia e
Espanha, sempre a partir dos dados abertos oficiais de cada país.

Gostaríamos de incluir Portugal com o ficheiro GTFS da CP com os horários planeados
(https://publico.cp.pt/gtfs/gtfs.zip), publicado no Ponto de Acesso Nacional (NAP Portugal,
registo 176). No NAP o conjunto de dados consta como "No licence – No contract", e não encontrámos
condições de utilização noutro local. Por isso, antes de usar os dados, pedimos a vossa
autorização.

O que faríamos com os dados:

- gerar a partir do GTFS listas de estações e de comboios (com os dias de circulação), quadros de
  partidas por estação, gráficos de circulação por linha e dados para a pesquisa de ligações;
- mostrar esta informação no site, com a indicação da fonte ("CP – Comboios de Portugal") e da data
  dos dados;
- publicar os ficheiros derivados (texto, formato TOML) no repositório público do projeto, como
  fazemos para os outros países.

As nossas perguntas:

1. Podemos reutilizar o GTFS da CP desta forma, incluindo a publicação dos ficheiros derivados?
2. Sob que licença? Uma licença aberta como a CC BY 4.0 (ou CC0) seria ideal; para Espanha usamos
   os dados da Renfe sob CC BY 4.0.
3. Que forma de atribuição pretendem (texto e, se for o caso, ligação)?

Uma resposta por escrito (este e-mail basta) seria ótima, para a podermos documentar junto da
fonte dos dados. Teremos todo o gosto em esclarecer qualquer dúvida.

Com os melhores cumprimentos,
Simon Legner
zugx — https://zugx.legner.me

## English

Dear Sir or Madam,

my name is Simon Legner and I develop **zugx** (https://zugx.legner.me), a free, ad-free website
for browsing train timetables — departure boards, a train index, graphic timetables and a journey
search. The project is open source (AGPL-3.0, https://github.com/simon04/zugx); it
currently covers Austria, Slovenia and Spain, always from each country's official open data.

We would like to add Portugal using CP's GTFS of planned timetables
(https://publico.cp.pt/gtfs/gtfs.zip), published on the National Access Point (NAP Portugal,
record 176). On the NAP the dataset is listed as "No licence – No contract", and we found no terms
of use elsewhere. So before using the data we would like to ask for your permission.

What we would do with the data:

- derive from the GTFS lists of stations and trains (with their running days), departure plans
  per station, graphic timetables per line, and data for the journey search;
- show this on the website, crediting the source ("CP – Comboios de Portugal") and the date of
  the data;
- publish the derived files (text, TOML format) in the project's public repository, as we do for
  the other countries.

Our questions:

1. May we reuse CP's GTFS in this way, including publishing the derived files?
2. Under which licence? An open licence such as CC BY 4.0 (or CC0) would be ideal; for Spain we
   use Renfe's data under CC BY 4.0.
3. What attribution would you like (wording and, if any, link)?

A written answer (a reply to this e-mail is enough) would be great, so that we can document it
next to the data source. We are happy to answer any questions.

Kind regards,
Simon Legner
zugx — https://zugx.legner.me
